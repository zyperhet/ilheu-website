       Then install: `npm install astro@latest @astrojs/mdx tailwindcss @tailwindcss/vite`

    2. Create `.nvmrc` containing exactly: `22`

    3. Create `astro.config.mjs`:
       ```javascript
       import { defineConfig } from 'astro/config';
       import tailwindcss from '@tailwindcss/vite';
       import mdx from '@astrojs/mdx';

       export default defineConfig({
         output: 'static',
         vite: {
           plugins: [tailwindcss()],
         },
         integrations: [mdx()],
       });
       ```
       Important: Do NOT install `@astrojs/cloudflare` adapter — it is for SSR only. Static sites need no adapter.

    4. Create `tsconfig.json`:
       ```json
       {
         "extends": "astro/tsconfigs/strict",
         "compilerOptions": {
           "strictNullChecks": true,
           "allowJs": true
         }
       }
       ```

    5. Create `src/styles/global.css`:
       ```css
       @import "tailwindcss";
       ```
       Use `@import "tailwindcss"` — NOT the v3 directives (`@tailwind base` etc.).

    6. Create an empty placeholder `src/content.config.ts` — just the file, no content (plan 02 will populate it):
